# Sample Research

This folder contains research outputs from an early, experimental version of this pipeline (v0.3). They are demonstrations of output shape, not validated research: no retrieval index was used and citations were never verified. The pipeline now takes its lineup per run and names no models, so the model line inside each report describes that one run only.

These are demonstrations of what the pipeline produces -- real model output from real runs, not documentation. Treat the content and citations as unverified.

## Reproducing

To try the same topics, run the current pipeline with the same topic prompt and a lineup of your choice (see `skills/storm-fusion-research/references/storm-method.md`). Results will differ, since models and their versions change over time.
