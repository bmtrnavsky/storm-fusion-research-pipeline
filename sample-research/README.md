# Sample Research

This folder contains research outputs generated by the STORM Fusion Research Pipeline. Each report was produced with an earlier (v0.3) version of this pipeline, which used a fixed four-model panel plus a separate fusing model. The pipeline now takes its lineup per run and names no models, so the model line inside each report describes that one run only.

These are demonstrations of what the pipeline produces -- real research outputs from real runs, not documentation.

## Reports

| File | Topic | Date | Method |
|------|-------|------|--------|
| `storm-architecture-2026-06-29.md` | Production-grade STORM architecture (topology, state, delivery, backpressure, observability) | 2026-06-29 | Fusion 4-model synthesis |
| `pkm-vs-pcm-2026-06-23.md` | PKM vs PCM: Personal Knowledge Management vs Personal Context Management | 2026-06-23 | STORM 6-perspective interviews (simulated + human) |

## Reproducing

To try the same topics, run the current pipeline with the same topic prompt and a lineup of your choice (see `skills/storm-fusion-research/references/storm-method.md`). Results will differ, since models and their versions change over time.
